## 一、数据库设计

| 表名 | 说明 |
|------|------|
| health_weight | 体重&BMI记录（BMI GENERATED ALWAYS AS 自动计算） |
| health_blood_pressure | 血压记录（收缩压/舒张压/心率） |
| health_blood_sugar | 血糖记录（空腹/餐后/随机） |
| health_heart_rate | 心率记录（静息/运动后/睡眠） |

- 复合索引 (user_id, record_date DESC) 优化查询
- 正常、异常、边界三类测试数据
