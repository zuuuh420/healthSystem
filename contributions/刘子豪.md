## 安全修复记录（2026-07-13）

| 修复项 | 文件 | 说明 |
|--------|------|------|
| 管理员权限校验 | AdminController.java, FoodController.java | 所有 `/admin/**` 和食物库写操作增加 `SecurityUtil.requireAdmin()` |
| JWT角色存储 | JwtUtil.java, AuthController.java, JwtAuthenticationFilter.java | JWT令牌中增加role字段，认证过滤器提取角色 |
| 角色工具方法 | SecurityUtil.java | 新增 `getCurrentUserRole()`, `isAdmin()`, `requireAdmin()` |
| 全局异常处理 | GlobalExceptionHandler.java | 捕获权限异常，返回403状态码 |
| 角色值校验 | AdminServiceImpl.java | `updateUserRole` 仅接受 admin/user，拒绝修改自己角色 |
| 删除保护 | AdminServiceImpl.java | `deleteUser` 禁止删除自己、禁止删除最后一个管理员 |
| 密码随机生成 | AdminServiceImpl.java | `resetPassword` 生成8位随机字母数字密码，不再固定为123456 |
| BMI自动计算 | HealthRecordServiceImpl.java | 根据身高(cm)和体重(kg)自动计算 BMI = 体重/(身高/100)² |
| 健康数据校验 | HealthRecordServiceImpl.java | 血压范围、舒张压<收缩压、心率30-220、身高50-250cm |
| 身高字段 | HealthRecord.java, HealthData.vue, V006_diet_admin.sql | 新增height字段用于BMI计算 |
| 前端错误提示 | HealthData.vue, UserManagement.vue | 处理后端校验错误提示，显示重置后的新密码 |
