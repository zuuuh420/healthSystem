# 部署说明

## 环境要求

| 环境 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17+ | 后端运行环境 |
| Maven | 3.6+ | 后端构建工具 |
| Node.js | 16+ | 前端构建环境 |
| MySQL | 8.0+ | 数据库 |
| Git | 2.30+ | 版本控制 |

## 一、项目结构

```
healthSystem/
├── health-backend/          # Spring Boot 后端
│   └── src/main/java/com/health/
│       ├── config/          # 配置类
│       ├── common/          # 工具类（JWT、Security、Result等）
│       ├── controller/      # 控制器
│       ├── service/         # 业务接口 & 实现
│       ├── mapper/          # MyBatis-Plus Mapper
│       ├── entity/          # 实体类
│       └── dto/             # 数据传输对象
├── health-frontend/         # Vue 2 前端
│   └── src/
│       ├── api/             # API 请求封装
│       ├── views/           # 页面组件
│       ├── router/          # 路由配置
│       └── utils/           # 工具函数
└── database/
    └── migrations/          # 数据库迁移脚本
```

## 二、数据库初始化

### 1. 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS health_system
  DEFAULT CHARSET utf8mb4
  DEFAULT COLLATE utf8mb4_general_ci;
```

### 2. 执行迁移脚本

```bash
# 按序号顺序执行
mysql -u root -p health_system < database/migrations/V006_diet_admin.sql
# 以及其他迁移脚本...
```

### 3. 检查表结构

```sql
USE health_system;
SHOW TABLES;
-- 应包含: user, food, diet_record, health_record, sport_record, sport_plan, sport_goal, check_in 等
```

## 三、后端部署

### 1. 修改配置文件

编辑 `health-backend/src/main/resources/application.yml`：

```yaml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/health_system?useUnicode=true&characterEncoding=utf8mb4&serverTimezone=Asia/Shanghai
    username: root
    password: 你的数据库密码
    driver-class-name: com.mysql.cj.jdbc.Driver

jwt:
  secret: 你的JWT密钥（至少256位随机字符串）
  expiration: 86400000  # Token有效期（毫秒），默认24小时
```

### 2. 打包

```bash
cd health-backend
mvn clean package -DskipTests
```

### 3. 运行

```bash
java -jar target/health-backend-0.0.1-SNAPSHOT.jar
```

后端启动后访问 `http://localhost:8080/api`，无报错即正常启动。

## 四、前端部署

### 1. 安装依赖

```bash
cd health-frontend
npm install
```

### 2. 修改API地址

编辑 `.env.production`（或 `.env.development`）：

```
VUE_APP_BASE_API = http://你的服务器IP:8080/api
```

### 3. 开发环境运行

```bash
npm run serve
```

### 4. 生产环境打包

```bash
npm run build
```

打包产物在 `dist/` 目录下。

## 五、Nginx 部署（推荐）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/health-frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

重启Nginx：
```bash
nginx -t          # 检查配置
nginx -s reload   # 重载配置
```

## 六、Docker 部署（可选）

### Dockerfile（后端）

```dockerfile
FROM openjdk:17-jdk-slim
COPY target/health-backend-0.0.1-SNAPSHOT.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "/app.jar"]
```

### 构建与运行

```bash
# 构建镜像
docker build -t health-backend .

# 运行容器
docker run -d -p 8080:8080 \
  -e SPRING_DATASOURCE_URL=jdbc:mysql://host.docker.internal:3306/health_system \
  -e SPRING_DATASOURCE_USERNAME=root \
  -e SPRING_DATASOURCE_PASSWORD=yourpassword \
  --name health-backend health-backend
```

### Docker Compose（MySQL + 后端 + 前端）

```yaml
version: '3.8'
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: yourpassword
      MYSQL_DATABASE: health_system
    ports:
      - "3306:3306"
    volumes:
      - ./database/migrations:/docker-entrypoint-initdb.d

  backend:
    build: ./health-backend
    ports:
      - "8080:8080"
    depends_on:
      - mysql
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/health_system
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: yourpassword

  frontend:
    build: ./health-frontend
    ports:
      - "80:80"
    depends_on:
      - backend
```

## 七、验证部署

2. 尝试注册新用户 → 登录 → 记录饮食/健康数据
3. 管理员登录后访问管理端页面，验证权限控制
4. 查看后端日志确认无异常
