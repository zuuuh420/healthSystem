## 一、食物库接口 `/foods`

### 1.1 分页查询食物列表

**GET** `/foods`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | String | 否 | 食物名称关键词搜索 |
| category | String | 否 | 按分类筛选 |
| page | int | 否 | 页码，默认1 |
| size | int | 否 | 每页条数，默认20 |

**响应：**
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "records": [{
      "id": 1, "name": "白米饭", "category": "主食",
      "caloriesPer100g": 116, "proteinPer100g": 2.6,
      "fatPer100g": 0.3, "carbsPer100g": 25.9,
      "unit": "g", "imageUrl": null, "description": "蒸熟白米饭"
    }],
    "total": 29, "size": 20, "current": 1
  }
}
```

### 1.2 获取全部食物

**GET** `/foods/all`

返回所有食物列表，按分类和名称排序。

### 1.3 获取食物分类列表

**GET** `/foods/categories`

**响应：**
```json
{ "code": 200, "data": ["主食", "蛋奶", "肉类", "蔬菜", "水果", "饮品", "豆制品", "油脂", "坚果", "甜点", "调味"] }
```

### 1.4 获取单个食物

**GET** `/foods/{id}`

### 1.5 新增食物 ⚠️需要管理员权限

**POST** `/foods`

**请求体：**
```json
{
  "name": "土豆", "category": "蔬菜",
  "caloriesPer100g": 81, "proteinPer100g": 2.0,
  "fatPer100g": 0.2, "carbsPer100g": 17.5,
  "unit": "g", "description": "新鲜土豆"
}
```

### 1.6 修改食物 ⚠️需要管理员权限

**PUT** `/foods/{id}`

### 1.7 删除食物 ⚠️需要管理员权限

**DELETE** `/foods/{id}`

### 1.8 批量导入食物 ⚠️需要管理员权限

**POST** `/foods/batch`

**请求体：** 食物对象数组

## 二、饮食记录接口 `/diet-records`

所有接口需要用户认证，数据按当前用户隔离。

### 2.1 创建饮食记录

**POST** `/diet-records`

**请求体：**
```json
{
  "recordDate": "2026-07-13",
  "mealType": "lunch",
  "foodId": 1,
  "quantityG": 200,
  "note": "午餐"
}
```
> `mealType` 取值：`breakfast`(早餐)、`lunch`(午餐)、`dinner`(晚餐)、`snack`(零食)

> 热量、蛋白质、脂肪、碳水由后端根据食物库数据自动计算

### 2.2 修改饮食记录

**PUT** `/diet-records/{id}`

请求体同上，会校验记录归属权。

### 2.3 删除饮食记录

**DELETE** `/diet-records/{id}`

校验记录归属权，非本人记录无法删除。

### 2.4 分页查询饮食记录

**GET** `/diet-records`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| date | String | 否 | 日期筛选（yyyy-MM-dd） |
| page | int | 否 | 页码 |
| size | int | 否 | 每页条数 |

### 2.5 按日期范围查询

**GET** `/diet-records/range`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start | String | 是 | 开始日期 |
| end | String | 是 | 结束日期 |

### 2.6 热量统计

**GET** `/diet-records/stats`

**响应：**
```json
{
  "code": 200,
  "data": {
    "todayCalories": 850.5,
    "todayProtein": 45.2,
    "todayFat": 28.6,
    "todayCarbs": 110.3,
    "weeklyAvgCalories": 920.1,
    "monthlyAvgCalories": 880.4,
    "dailyCalories": [
      { "date": "2026-07-07", "totalCalories": 900.0 },
      { "date": "2026-07-08", "totalCalories": 850.5 }
    ]
  }
}
```
> 空数据统计使用 `COALESCE`，无记录时返回0而非null。

## 三、健康数据接口 `/health-records`

所有接口需要用户认证，数据按当前用户隔离。

### 3.1 记录健康数据

**POST** `/health-records`

**请求体：**
```json
{
  "recordDate": "2026-07-13",
  "height": 170.0,
  "weight": 65.0,
  "systolicPressure": 120,
  "diastolicPressure": 80,
  "bloodSugar": 5.6,
  "heartRate": 72,
  "note": "晨起测量"
}
```
> BMI 由后端根据身高(cm)和体重(kg)自动计算：`BMI = 体重 / (身高/100)^2`

> 校验规则：
> - 收缩压(60-260) > 舒张压(30-160)
> - 心率 30-220 次/分
> - 身高 50-250cm
> - 体重 > 0

### 3.2 修改健康数据

**PUT** `/health-records/{id}`

请求体同上，校验记录归属权。

### 3.3 删除健康数据

**DELETE** `/health-records/{id}`

校验记录归属权。

### 3.4 查询个人健康数据

**GET** `/health-records`

### 3.5 按日期范围查询

**GET** `/health-records/range`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| start | String | 是 | 开始日期 |
| end | String | 是 | 结束日期 |

## 四、管理端接口 `/admin`

⚠️ **全部接口需要管理员权限**，普通用户调用返回403。

### 4.1 系统统计

**GET** `/admin/stats`

**响应：**
```json
{
  "code": 200,
  "data": {
    "totalUsers": 15, "totalHealthRecords": 45,
    "totalDietRecords": 120, "totalSportRecords": 80,
    "totalFoods": 29
  }
}
```

### 4.2 用户列表

**GET** `/admin/users`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | String | 否 | 按用户名/昵称搜索 |
| page | int | 否 | 页码 |
| size | int | 否 | 每页条数 |

### 4.3 修改用户角色

**PUT** `/admin/users/{id}/role`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| role | String | 是 | 仅允许 `admin` 或 `user` |

> 不能修改自己的角色

### 4.4 删除用户

**DELETE** `/admin/users/{id}`

> 不能删除自己，不能删除最后一个管理员

### 4.5 重置用户密码

**PUT** `/admin/users/{id}/reset-password`

**响应：**
```json
{ "code": 200, "msg": "密码已重置", "data": "aB3xK9mQ" }
```
> 返回随机生成的新密码（8位字母数字混合），仅在本次响应中返回

## 通用说明

### 认证方式
所有接口（除 `/auth/login`、`/auth/register` 外）需在请求头中携带 JWT Token：
```
Authorization: Bearer <your_token>
```

### 统一响应格式
```json
{
  "code": 200,    // 200成功, 400参数错误, 403权限不足, 401未认证
  "msg": "提示信息",
  "data": {}
}
```
